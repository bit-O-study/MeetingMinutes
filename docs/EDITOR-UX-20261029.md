# 편집 화면과 채팅 피드백

## 2026-10-30 작성자 이름 연결

- 커서 확장의 사용자 설정이 `id`를 누락한 채 awareness 사용자 정보를 덮어쓰던 원인을 수정했다. 이름·이미지·ID를 함께 유지한다.
- 운영 WebSocket은 권한 검사에서 확인한 사용자 ID를 연결에 묶는다. 인증된 연결은 클라이언트의 커서 정보로 작성자가 바뀌지 않는다. 화면은 기존처럼 이름만 보여 준다.
- 브라우저 검증에 실제 본문 편집 → 이력 자동 생성 → 작성자 일치 및 이름 표시 검증을 추가했다. 기존 작성자 없는 이력은 추정으로 수정하지 않는다.

- 사진·이력·공유 버튼은 모바일에서도 한 줄로 읽히며 축소되지 않는다. 연결 상태는 제목 헤더 우측, 더보기 메뉴 위에 표시한다.
- 모바일 이력/공유는 본문 아래에 숨기지 않고 본문 자리에 표시한다. 데스크톱의 본문+보조 패널 구조는 유지한다.
- 이력은 열린 동안 갱신하고 실패·재시도·미리보기 로딩을 구별한다. 다른 시점을 선택하면 이전 미리보기로 복원하지 못하게 한다. 사진 및 같은 제목 구획의 변경도 기록한다.
- 채팅은 작성 중/전송 중을 표시하고 성공 안내는 3초 후 사라진다. 새 입력 시 이전 성공 안내를 지우며 실패는 재시도할 수 있도록 유지한다.
- 검증 완료: 단위 테스트 72개, 타입 검사, Next.js 16.4.3 운영 빌드 통과. 린트 오류 0개(기존 Avatar 이미지 경고 1개).
- Playwright로 320/390/430/1280px 도구 모음, 연결 상태 위치, 모바일 패널과 하단 메뉴 겹침, 이력 목록 자동 갱신·선택·사진 미리보기·실패/재시도를 확인했다. 채팅 작성 상태, 전송 성공 안내의 3초 후 해제, 후속 입력, 실패 안내 유지, 초안 보존 및 재시도도 통과했다.
- 브라우저 검증은 임시 사용자/프로젝트/이력을 만들고 종료 시 삭제한다. 사진 미리보기는 테스트 이미지 응답을 사용하며 실제 사진 업로드 경로의 종단 간 검증은 포함하지 않는다. 재현 스크립트: `scripts/verify-editor-feedback.mjs` (로컬 앱·공동 편집 서버와 테스트 DB 접속 환경 필요).
- 이 기록은 로컬 검증 결과이며 운영 배포 완료를 의미하지 않는다.
