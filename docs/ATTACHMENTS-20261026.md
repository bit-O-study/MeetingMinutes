# 프로젝트 첨부 파일 (2026-10-26)

사용자 직접 요청에 따라 노트 사진과 프로젝트별 앱 패키지 공유를 추가했다. 프로젝트 멤버십이 권한 경계이며, 별도 파일 공개 링크는 만들지 않는다.

## 사용

- 노트: 사진 버튼, 이미지 붙여넣기, 이미지 드롭. JPG/PNG/WebP, 파일당 5MiB 이하.
- 프로젝트 → 배포 파일: APK/AAB/APKS/ZIP, 파일당 64MiB 이하. 버전·변경 내용과 함께 보관하고 프로젝트 멤버에게 다운로드 주소를 공유한다.
- 패키지는 페이지당 100개 표시하고 이전/다음으로 탐색한다. APK/AAB는 ZIP 파일 목록과 manifest 경로를 검사하지만 빌드·서명 검증을 대신하지 않는다.
- 사진은 같은 프로젝트의 다른 노트에 복사할 수 있다. 최초 업로드 노트가 삭제되어도 프로젝트에 속한 사진은 유지한다.
- 공개 노트에서는 유효한 공유 토큰, 공유 생성자의 현재 멤버십, 같은 프로젝트, 현재 공유 본문의 사진 참조를 모두 검사한다. 토큰 만료·폐기·탈퇴·본문에서 사진 제거 후 접근은 차단된다. APK는 노트 공유 토큰으로 내려받을 수 없다.

## 저장소와 배포

- 개발 기본값은 `.data/uploads`이며 Git에서 제외한다.
- Windows/직접 호스팅 운영에서는 `MOA_UPLOAD_DIR`에 릴리스 폴더 밖의 절대 경로를 지정해야 한다. DB와 해당 디렉터리를 함께 백업해야 한다.
- Vercel에서는 현재 파일시스템 저장을 지원하지 않는다. 저장소 미설정 시 UI를 비활성화하고 API는 503을 반환한다. Blob 등 영구 저장소 또는 Windows 호스팅 선택은 사용자 답변 대기이며 운영 업로드 완료로 보고하지 않는다.
- 저장 파일명은 UUID, 덮어쓰기 금지. MIME은 파일 헤더로 판정하고 다운로드는 no-store/nosniff, UTF-8 파일명을 사용한다.
- 프로젝트 삭제 후 실제 파일의 자동 정리와 총 저장용량 할당은 아직 구현하지 않았다. 현재 생성되는 메타데이터 없이 남은 파일은 별도 보존/정리 정책이 필요하다.

## DB

`0009_project_files.sql`은 프로젝트·업로더·원본 노트 및 파일명/크기/SHA-256/버전/설명을 저장한다. RLS를 켜고, 앱의 서버 DB 계정과 중앙 멤버십 검사로 접근한다. 원본 노트 FK는 SET NULL이다.

2026-10-26 확인 당시 연결 DB는 0007까지만 적용되어 있었다. `scripts/apply-project-files.mjs`로 기존 0008 보안 마이그레이션과 0009를 단일 트랜잭션에 적용했다. 실행 전 앱 계정 RLS bypass와 기존 마이그레이션 해시를 확인했고, 실행 후 기존 노트·사용자·초대·공유 행 수 보존과 새 테이블 RLS를 검증했다. 별도 임의 db push는 하지 않았다.

## 검증

- `src/lib/attachment-input.test.mts`: 사진/패키지 형식·크기, 정규 본문 참조, 고유 경로/덮어쓰기 방지, 실제 파일 바이트 보존, 서버리스 임시 저장 거부 4개 통과.
- `scripts/verify-attachments.mts`: 실제 localhost3291 API에서 로그아웃/비회원/다른 origin/위장 사진 차단, 사진·APK 바이트 왕복, 현재 공유 본문 참조, 패키지 공개 차단, 원본 노트 삭제 후 복사 사진 유지, 공유 만료/폐기/멤버 제거 차단 통과. 생성한 테스트 파일·프로젝트·사용자 정리 완료.
- UI 및 공동 편집 검증은 별도 editor/project-packages 검증 스크립트를 사용한다.

### 실제 화면 검증 추가

- `scripts/verify-project-packages.mts`: ZIP/APK 업로드 → 목록 반영 → 다운로드 파일명/바이트 일치, 잘못된 APK의 400 응답 후 파일·버전·설명 보존, 101개 목록의 100/1 페이지 이동 및 입력 초안 유지, 모바일 390px 가로 넘침 없음. 결과 `logs/project-packages/result.log`, 테스트 데이터·파일 정리 완료.
- `scripts/verify-editor-collaboration.mts`: 두 사용자 커서 이름·색·아바타, 같은 사용자 중복 탭, 문서 중간 문단·제목·목록 Tab/Shift+Tab, 저장 확인 시각과 삭제만 한 변경, 사진 선택·붙여넣기·드롭·상대 화면 반영·재접속 유지, 오프라인 한글 입력과 연결 상태 복귀, 320px 가로 넘침 없음, 퇴장 사용자 정리 통과. 임시 사진과 DB fixture 정리 완료.
- 전체 단위 테스트 112개 통과. 저장소 trace 제외 지시와 오프라인 복귀 수정까지 포함한 최종 통합 build 성공, 빌드 경고 없음. 대상 TypeScript/ESLint 통과. 운영 웹 배포는 아직 하지 않았다.
