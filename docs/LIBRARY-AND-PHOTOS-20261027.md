# 관리자 자료실과 메모 사진

사용자 요청으로 자료실 UI/업로드를 통합 관리자 `/admin/library`로 이동한다. 기존 파일·검수 기록·서버 디스크를 유지한다. 모아의 전역/프로젝트 자료실 메뉴를 제거하고 이전 페이지는 관리자 자료실로 이동한다. 일반 프로젝트 패키지 업로드 API는 410을 반환하고 패키지 다운로드는 관리자 API를 이용한다.

사진은 메모 편집기의 사진 버튼, 붙여넣기, 드래그로 추가한다. 5MB 이하 JPG/PNG/WebP만 허용한다. 메모 접근 권한을 검사한 뒤 noteId/spaceId/userId/파일명/크기/만료가 서명된 티켓으로 운영 디스크에 직접 업로드한다. 저장소는 업로드와 다운로드에서 멤버십, 삭제되지 않은 메모와 스페이스를 재검사한다. 외부 이미지 URL과 SVG는 허용하지 않는다. 사진은 기존 Yjs 문서와 자동 저장/읽기 전용 렌더러를 사용한다. 사진 다운로드는 멤버 인증이 필요하다.

관리자 자료실은 기존 파일 목록·검색·검수·다운로드에 프로젝트별 업로드를 제공한다. 관리자 세션을 검증한 API만 패키지 업로드 티켓을 발급한다. 관리자 이메일에 연결된 모아 계정이 필요하며 계정을 자동 생성하지 않는다.

main 코드 push의 Windows storage workflow에서 웹 검사와 APK를 빌드한다. 기존 APK 서명 키를 암호화 secret에 보관해 업데이트 호환성을 유지한다. versionCode=1000+run_number, versionName=1.1.run_number. 서버 배포 성공 후 APK를 영구 디스크에 올리고 `모바프로젝트` 자료실에 버전·커밋·워크플로 실행을 기록한다. 같은 파일명·해시는 재실행에서 중복 등록하지 않으며 다른 해시는 실패한다. 원본 APK와 서버 파일/DB 해시를 대조한다. 실패 시 GitHub publish job도 실패한다. 문서만 변경한 push는 기존 정책대로 빌드를 생략한다.

로컬 검증: 모아 테스트 70개, 타입 검사, lint(기존 Avatar 경고 1), production build 통과. 관리자 production build 통과. 운영 배포/브라우저 사진 저장·재조회·권한 및 APK 자동 등록은 배포 후 확인한다.
